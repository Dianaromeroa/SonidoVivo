# Sonido Vivo — Prompts para imágenes de productos

Este documento fue generado desde `src/data/productosIniciales.js` y contiene **51 prompts**, uno por cada producto inicial del catálogo.

## Flujo de trabajo

1. Busca el producto por su ID.
2. Copia el bloque de texto completo bajo **Prompt para copiar**.
3. Genera una imagen cuadrada de catálogo en la herramienta de IA que prefieras.
4. Exporta o convierte el resultado a **WebP**, con tamaño recomendado de **1024 × 1024 px**.
5. Guarda el archivo en `public/productos/` usando exactamente el nombre indicado, por ejemplo `ga001.webp`.
6. No agregues texto, precios, bordes ni marcas de agua a la imagen.

## Convención de archivos

- Carpeta de destino: `public/productos/`
- Formato final: `.webp`
- Nombre: ID del catálogo en minúsculas. Ejemplo: `GA001` → `ga001.webp`.
- Mantén fondo verde salvia claro `#E6F1ED`, formato 1:1 y el mismo estilo entre imágenes.

> Nota: el ID, marca, modelo y precio se muestran como texto en Sonido Vivo. No deben aparecer escritos dentro de las imágenes generadas.
